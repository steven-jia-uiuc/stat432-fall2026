title: "What Counts as Checking AI-Generated Work?"
author: "Steven Jia (gjia3)"
---

When homework solutions and AI coding agents are both available, what should count as a substantive attempt and adequate verification of AI-generated statistical work? Is rerunning the code and confirming that it produces output enough, or should a student also derive important steps, test the code on a simpler example, and explain the statistical meaning of every result? More generally, how can we distinguish between using an AI agent as a learning and checking tool and relying on it in a way that replaces our own understanding?
